# Keybinds

`Mod` is the Super key (Windows/Command key).

## Terminal & Apps

| Keybind | Action |
|---------|--------|
| `Mod+Return` | Open terminal (foot) |
| `Mod+T` | Open terminal (foot) |
| `Mod+Alt+Return` | Open terminal in tmux session |
| `Mod+Shift+Return` | Open default browser |
| `Mod+B` | Open qutebrowser |
| `Mod+Shift+B` | Open the preferred browser |
| `Mod+E` | Open Nautilus file manager |
| `Mod+Shift+N` | Open default editor |

## Launcher

| Keybind | Action |
|---------|--------|
| `Mod+Space` | App launcher |
| `Mod+D` | Quick commands palette |
| `Mod+Alt+Space` | Toggle full palette |
| `Mod+Alt+C` | Capture category |

## Window Management

| Keybind | Action |
|---------|--------|
| `Mod+Q` / `Mod+W` | Close window |
| `Mod+O` | Toggle overview |
| `Mod+H/J/K/L` | Focus left/down/up/right |
| `Mod+←/↓/↑/→` | Focus column/window |
| `Mod+Ctrl+H/J/K/L` | Move window |
| `Mod+Shift+H/L` | Focus monitor left/right |
| `Mod+Shift+J/K` | Move column to workspace down/up |

## Workspaces

| Keybind | Action |
|---------|--------|
| `Mod+1-9` | Focus workspace 1–9 |
| `Mod+Ctrl+1-9` | Move column to workspace 1–9 |
| `Mod+Tab` | Next workspace |
| `Mod+Shift+Tab` | Previous workspace |
| `Mod+Page_Down/Up` | Next/previous workspace |

## Audio

| Keybind | Action |
|---------|--------|
| `XF86AudioRaiseVolume` | Volume up |
| `XF86AudioLowerVolume` | Volume down |
| `XF86AudioMute` | Toggle output mute |
| `XF86AudioMicMute` | Toggle microphone mute |
| `XF86AudioPlay` | Play/pause media |
| `XF86AudioNext` | Next track |
| `XF86AudioPrev` | Previous track |

## Brightness

| Keybind | Action |
|---------|--------|

| `XF86MonBrightnessDown` | Display brightness down |
| `XF86KbdBrightnessUp` | Keyboard brightness up |
| `XF86KbdBrightnessDown` | Keyboard brightness down |

## Screenshots

| Keybind | Action |
|---------|--------|
| `Print` | Screenshot (region select) |
| `Mod+Print` | Color picker |
| `Mod+Alt+Shift+R` | Start or stop screen recording |
| `Ctrl+Print` | Screenshot (full screen) |
| `Shift+Print` | Screenshot to clipboard |
